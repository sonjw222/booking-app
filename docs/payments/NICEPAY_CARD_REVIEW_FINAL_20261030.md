## 5. NICEPAY 심사용 센터·계정
### 5.1 구조(P2/P2b 적용 전제)
- P2(`add_nicepay_review_center_isolation_20261028.sql`)·P2b(`fix_nicepay_gate_reviewer_flag_20261029.sql`): **운영 적용·검증 완료**(게이트 `off`, 심사관 0, 심사 센터 0 — 10/31 P3 사전 검토 시점). 심사 센터(`is_nicepay_review=true`)는 일반 회원·토스 심사관·비로그인에게 어떤 경로로도 보이지 않고, 전용 권한 `accounts.nicepay_review_access` 계정에게만(그리고 운영 센터는 그 계정에게 숨김) 보인다.
- **실제 운영 서비스와 심사 상품의 관계**: 심사 센터는 실제 센터가 아니다 — 수업·강사·주소·사업자번호가 없고(주소·사업자번호는 임의 값 금지로 null) 일반 이용자에게 노출되지 않는다. 심사 상품은 결제 절차 확인용 **심사용 거래**이므로 "존재하지 않는 수업·서비스를 실제 상품처럼" 만들지 않도록 이름·설명에 심사용임을 밝혔다. 운영 센터(실제 서비스)의 상품은 심사관에게 숨겨져 심사관이 운영 상품으로 결제할 수 없다(앱 선검사 + DB 트리거 이중).

### 6.2 PC/모바일·EUC-KR·금액·주문번호·ReturnURL

## 8. 카드사 심사 신청까지 남은 항목
1. **실제 판매 상품 등록**(공개 목록 비어 있음 방지) + "테스트" 상품 비공개(§4).
2. **사업장 주소 푸터 공개 승인**(Vercel `NEXT_PUBLIC_SHOW_BUSINESS_ADDRESS_IN_FOOTER=true` + 재배포 — 배포가 곧 공개). 사업자등록증과 주소 일치 확인.
3. **NICEPAY 계약 정보**: 정식 상호·위탁 범위/보유 기간(법적 고지 구체화), MID(단건 `mwhabit01m`)·MerchantKey 발급, 허용 호스트·요청 Amt 패딩·WebView(WapUrl/IspCancelUrl) 확인.
4. **법적 고지 시행일·공지 절차 결정**(§2.3).
5. **P3 실행 승인**: 심사 센터·상품(이름·가격·기간 확정) → 심사 전용 계정 이메일 확정 → 지정(§5.4).
6. **결제 활성화 승인**: 환경변수(Vercel) → `NICEPAY_CHECKOUT_ACTIVATED=true` 코드 변경 PR → 게이트 `reviewer`(심사 기간만) → 샌드박스 실결제창 확인(실제 SDK·모바일 실기기는 현재 BLOCKED).
7. 심사 종료 후 `close_nicepay_review_20261029.sql` 로 원복.
