## 2. 기간 규칙(서버 실제 로직 그대로)
이용 시작일 = 결제일(KST). 예외: 월 갱신형이 조기이용 불허면 컷오프 규칙의 달 1일. 만료일: none→없음, days→결제일+N, date→상품 고정일, rolling_month→달 말일. 서버 함수 `calc_rolling_month_dates` 와 JS 계산이 2026–2028 전 날짜×컷오프 1–31 에서 일치(PGlite 단위 테스트). 정보가 없으면 추측하지 않고 표시 안 함. "모든 수강권 1년 유효" 문구 없음.
