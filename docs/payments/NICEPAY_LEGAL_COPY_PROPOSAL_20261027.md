# NICEPAY 전환에 따른 법적 안내 문구 점검·수정안 (2026-10-27) — 제안서, 아직 적용하지 않음

범위: `/legal/terms` · `/legal/refund` · `/legal/privacy` · `/legal/business` 의 **결제대행사(PG) 서술**만. 약관상 책임·환불 조건·청약철회 기준은 바꾸지 않는다. 이 문서는 수정안만 담고, 페이지는 수정하지 않았다(법적 문구는 사용자 승인 후 적용).

## 1. 현재 상태(사실)
- 계약: NICEPAY 독립몰 계약 접수·전자계약 서명 완료, MID(단건 `mwhabit01m`, 정기 `mwhabit02m`)는 **발급 예정**. 즉 **아직 NICEPAY 로 결제가 처리되는 상태가 아니다.**
- 앱: 일반 회원용 온라인 PG 결제는 **비활성**(`PG_CHECKOUT_ENABLED` 꺼짐, 직접결제·센터 현장 결제만). 심사관 전용 계정 오버라이드(`accounts.pg_checkout_override`)만 예외. 결제수단은 PG 가 켜진 사용자에게 센터 설정(`pay_methods`)대로 노출되며 `HIDDEN_PAY_METHOD_IDS` 는 현재 비어 있다(`lib/payMethods.ts`) — 카카오페이·토스페이도 코드상 숨겨져 있지 않다. 이 둘은 토스 전용 결제수단이라 NICEPAY 계약 범위에서 제공되는지는 별도 확인이 필요하다.
- 즉 현재 시점에 "토스페이먼츠를 통해 직접 수납한다"는 서술은 **사실이 아니거나 곧 사실이 아니게 된다.**

## 3. 수정안 (2단계)
### 단계 A — 지금 적용 가능(계약 진행 중·결제 비활성, 특정 PG 를 확정하지 않음)
- `/legal/business`: "다만 회원의 결제 대금 수납은 모하빗이 결제대행사를 통해 직접 처리하며, 이와 관련한 사항은 환불·취소 정책을 따릅니다. (현재 온라인 카드 결제는 준비 중이며, 서비스에서 제공하는 결제 수단은 구매 화면에 표시된 것에 한합니다.)"
- `/legal/terms` 제9조: "…대금 결제는 회사가 제공하는 결제 수단(구매 화면에 표시되는 신용카드 등 온라인 결제, 계좌이체 또는 센터 현장 결제)을 통해 이루어집니다. 온라인 결제 수단으로 결제한 대금은 회사가 결제대행사를 통해 직접 수납하며, 회사는 별도의 정산 절차를 통해 해당 대금을 센터에 지급합니다. 센터 현장 결제만 회사를 거치지 않고 회원이 센터에 직접 지급합니다." — 개별 결제수단(카카오페이·토스페이) 열거를 구매 화면 기준 문구로 대체(수단 목록이 바뀔 때마다 약관을 고치지 않도록). **정산·직접 수납 구조 자체는 그대로.**
- `/legal/refund` 4: "온라인 결제수단으로 결제한 건은 결제대행사를 통해 승인 취소되고, 계좌이체로 결제한 건은 등록하신 계좌로 재입금하는 방식으로 환불됩니다. …(이하 동일)" — 환불 기간·조건 문장은 변경 없음.
- `/legal/privacy` 위탁 표: `토스페이먼츠` 행을 "결제대행사 — 온라인 PG 결제 기능 활성화 시 결제 승인·취소 처리(활성화 시점에 상호를 구체적으로 고지)"로 일반화.

### 단계 B — NICEPAY 결제를 실제로 켜는 시점(MID 발급·결제 활성화 변경(NICEPAY 준비 브랜치의 `NICEPAY_CHECKOUT_ACTIVATED` 해제)과 같은 변경)
- 위 4곳의 "결제대행사"를 **NICEPAY 의 정식 상호**로 구체화한다. 정식 상호·소재지·위탁 항목은 **계약서(전자계약) 기준으로 사용자가 확인**해야 한다 — 이 문서에서 추측하지 않는다: `[결제대행사 정식 상호 — 계약서 기준 확인 필요]`.
- 위탁 표: 수탁자 / 위탁 업무(결제 승인·취소·정기결제 처리) / 보유·이용 기간(관련 법령에 따른 보존) — 계약·처리방침 법무 검토 후 확정.
- 정기결제(센터 구독료)에 쓰는 별도 MID(`mwhabit02m`) 서술은 `docs/payments/NICEPAY_SUBSCRIPTION_DOMAIN_20261017.md` 와 맞춰 별도 승인.

## 4. 적용하지 않은 이유 / 승인 필요 사항
- 약관·처리방침 문구는 법적 효력이 있는 공개 문서라 사용자(필요하면 법무) 확인 전에는 수정하지 않는다.
- NICEPAY 심사관은 약관·환불·처리방침의 PG 서술이 계약과 맞는지 볼 수 있다. 단계 A 는 심사 전에 적용하는 것을 권장하지만 적용 여부와 정확한 표현은 사용자가 결정한다.
- 환불 기준(7일 이내 등)·책임 분담 문장은 이 제안 어디에서도 바뀌지 않는다.
