## 3. NICEPAY 기술지원팀이 공식 회신한 내용 (2026-10-30)

근거: Gmail 기술지원 이메일(메일 제목 `[RE]...NICEPAY v3 ...`, 수신 2026-10-30 15:09 KST). 개인 비밀번호·상점키는 이 문서에 포함하지 않는다.

- 테스트용 인증 결제 MID: `nicepay00m`. 공용 테스트 가맹점관리자에서 상점키 확인 안내를 받았으나 실제 마스킹 해제에 필요한 정산계좌 인증이 되지 않음 → **별도 후속 문의 발송, 답변 대기**.
- 인증결제는 **2TR**: 카드 인증 완료와 실제 승인 완료가 다름. 인증 성공 후 별도 승인 요청이 없다면 결제 완료 아님. 안전한 QA는 승인 API 0건.
- v3 결제 요청 **Amt는 12자리 0 패딩 없이 실제 금액 숫자만** 사용하라고 답변받음(예: 15000).
- PC 웹은 팝업, 모바일은 페이지 이동. 모바일에 서버 인증 결과 `ReturnURL`을 반드시 설정해야 함.
- WebView 앱 전용 자세한 사양은 개발자센터 앱 연동 문서 및 공식 샘플코드를 참조하라고 안내받음. 구체적인 모하빗 앱 복귀 스킴이 승인·확인된 것은 아님.
- 계약/상품/심사 요건은 기술지원 소관이 아니므로 영업부서에 문의하라는 답변을 받았고 **2026-10-30 영업팀으로 별도 이메일 문의 발송 완료**.
