## 경로 설계(최소 권한)
1. **심사 계정**: `niceqa@mwhabit.com` 일반 회원 계정(센터 매니저 아님, `nicepay_review_access=true`). 로그인 URL: `https://mwhabit.com/login`.
2. **허용 목록**(`nicepay_review_center_grants`, 이미 로컬 검증 완료한 `add_nicepay_review_real_center_grants_20261103.sql`): 계정↔센터 1행, `can_purchase=false`(조회 전용).
3. **심사관 화면**: 홈·검색은 허용 센터(A10TION)만 보인다(별도 심사 센터·테스트 상품은 탐색에서 제외 — 허용 해제 시 원복). 센터 상세는 구매·담기·예약 버튼 없이 상품 정보·가격·이용기간을 보여 주고, 상품 행의 **"결제 화면 · 카드 결제창 확인"** 으로 결제 화면에 들어간다.
4. **결제 화면**: 실제 결제 버튼은 "조회 전용 — 구매할 수 없어요"로 잠기고, **"카드 결제창 확인(승인 없음)"** 카드(`review-window`, 공용 테스트 MID)만 동작한다. 인증창은 열리지만 승인·망취소·환불·주문·이용권 발급은 없다(서버 포트가 읽기 전용, 정적 테스트로 강제).
5. **서버 판정**(`reviewWindowRuntime.readTarget`): 지정 계정 + 심사 권한 + 활성·판매 중·미만료 상품 + (심사 센터 상품 **또는** 허용 행이 있는 승인된 비내부 실제 센터 상품). 허용 테이블이 없으면(SQL 전) 기존 심사 센터만.
6. 기존 가상 테스트 상품은 **삭제·정상 상품화하지 않는다**(이름·설명은 "테스트 상품"으로 이미 정리됨). 허용 행이 있으면 심사관 탐색에서만 빠진다.
