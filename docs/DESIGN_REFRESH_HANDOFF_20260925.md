# 모하빗 디자인 개편 — 로컬 인계

## 기준과 범위

- 브랜치: `design/mwhabit-ui-refresh-20260925`
- 기준 main: `9864e44c7724a3377f034aaf8ddec1555754d5b7`
- 기존 네이비·화이트·라이트그레이 토큰을 유지한다.
- 모바일 고정 4탭, 태블릿 rail, 웹 sidebar에 같은 회원 메뉴를 사용한다.
- GitHub 반영은 사용자가 수행한다. 이 작업에서 main 병합·원격 push·배포는 하지 않았다.
- SQL/RLS/결제 API/네이티브 iOS·Android 파일은 변경하지 않았다.

## 검증의 범위

- 단위 테스트 및 공용 컨트롤의 DOM 키보드 테스트: 65개 파일, 472개 테스트 통과.
- 프로덕션 빌드와 TypeScript 검사 통과. Supabase의 실제 비밀값 없이 빌드용 placeholder URL/key로 실행했다.
- 브라우저 설치를 시도했으나 다운로드 아카이브 오류로 실패했다. 따라서 Playwright 화면 렌더링·스크린샷·실기기 시각 검증은 완료했다고 간주하지 않는다.
- 실제 로그인/OTP/예약/주문/결제/위치 권한 흐름은 운영 또는 테스트 계정에서 별도 확인이 필요하다. 단위 테스트 통과는 이 흐름의 실서비스 검증을 의미하지 않는다.
- 수업 검색은 최대 100개 후보에 필터를 적용한다. 모든 수업에 대한 서버측 위치 검색이나 전체 결과 집계를 구현한 것은 아니다.
- 화면에 남은 기존 업무 기능의 전체 재구현이나 모든 과거 TODO 처리는 이 디자인 개편 범위가 아니다.

## Mac에 적용

다운로드한 `mwhabit-design-overhaul-20260925.patch`를 사용한다. 실제 저장소의 작업 중 변경과 native 설정을 보존하기 위해 별도 worktree에 적용한다.

먼저 현재 실제 저장소 폴더에서 다음을 확인한다.

```sh
git status --short --branch
git fetch origin
git worktree add -b design/mwhabit-ui-review ../booking-app-design-review origin/main
cd ../booking-app-design-review
git am --3way ~/Downloads/mwhabit-design-overhaul-20260925.patch
```

같은 이름의 브랜치/폴더가 이미 있으면 삭제하거나 덮어쓰지 말고 다른 이름을 사용한다. 최신 main과 충돌하면 그 시점에서 멈추고 충돌을 확인한다. 적용을 포기하려면 해당 worktree에서 `git am --abort`로 패치 적용만 취소할 수 있다.

패치 적용 후 이 별도 폴더에서 의존성과 환경변수를 준비해 확인한다. `.env.local`의 실제 값은 채팅에 붙여넣지 않는다.

```sh
npm ci
npm test
npm run build
npm run dev
```

모바일 390px, 태블릿 768/1024px, 웹 1280px 이상에서 홈·찾기·예약·마이·가입·센터 구매·관리 화면을 확인한다. 라이트 모드부터 확인하고, 다크 모드와 키보드 조작도 확인한다.

검토한 분리 브랜치만 GitHub에 올릴 때:

```sh
git push -u origin design/mwhabit-ui-review
```

이 명령은 main을 병합하지 않는다. 저장소에 연결된 자동화가 있다면 브랜치 push로 미리보기 배포 등이 실행될 수 있다.
