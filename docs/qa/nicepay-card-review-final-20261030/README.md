# 증빙 안내 — 격리 환경 모의 검증 (운영 거래 아님)

이 폴더의 스크린샷·JSON 은 **로컬 일회용 Supabase + 모의 NICEPAY 결제창/모의 승인 서버**에서 만든 것이다.
- "결제가 완료됐어요"(`08-reviewer-result-done-*`)는 **격리 DB 의 모의 승인 결과**이며 실제 NICEPAY 결제·실제 운영 거래·실제 청구가 아니다. 실제 NICEPAY 호출 0건.
- 화면의 "[QA]…"·"(심사용)" 센터·상품과 계정은 격리 fixture 이며 운영 데이터가 아니다. 운영의 NICEPAY 결제는 활성화되지 않았다(코드 상수·DB 게이트 OFF).
- `mock-calls-summary.json` 의 APPROVE/NETCANCEL 은 로컬 모의 서버가 센 호출 수다.
- 푸터의 고객센터 번호는 서비스가 이미 공개 중인 사업자 연락처다. 사업장 주소는 이 증빙 어디에도 없다.
