## 이번 PR 변경(#248, 정책 결정 없음)
- **이름 없는 `button.switch` 전수 정리**: 관리자 배너·구독 플랜, 체크아웃 자동 예약, 운영 설정(당일 예약), 수강권 규칙 6개, 상품 2개, 기간 옵션 2개 — 화면에 보이는 기능명과 같은 `aria-label` + `role="switch"` + `aria-checked`. 정적 테스트가 앞으로 이름 없는 switch 를 막는다(`tests/unit/permissionGate.test.ts`).
- **권한 게이트**: `lib/permissionGate.ts`(`resolvePermissionGate`) — **권한 조회 중(loading)·조회 실패(error)는 허용이 아니다**. `/manager/alimtalk`(홈·보내기·규칙·템플릿·설정)는 메뉴와 같은 `message.alimtalk.view`, `/manager/sales` 는 `pass.sales.view` 가 있어야 본문이 열리고, 없으면 "…화면을 볼 권한이 없어요" 안내(0원 화면 없음). 오너는 전권(조회 불필요). 권한 키·서버 정책 변경 없음(UI 안내일 뿐 실제 차단은 서버/RLS).
- 보내기 화면은 예전에 "조회 중(null)"일 때 본문을 그렸다 — 공유 게이트로 교체.
