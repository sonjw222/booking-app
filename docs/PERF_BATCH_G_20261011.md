## 측정의 범위

React/jsdom 합성 센터 1,000개, 같은 컴포넌트의 수정 전/후 단회 측정:

| 항목 | 이전 | 이후 |
|---|---:|---:|
| 첫 렌더 카드 | 1,000 | 30 |
| 첫 렌더 시간(ms) | 224.41 | 23.66 |
| 최초 + 탭 전환 자격 확인 | 2 | 1 |
| 최초 + 탭 전환 목록 조회 | 2 | 2 |

시간은 jsdom 측정으로 실제 브라우저·DB 네트워크 지연과 다르다. SQL 실행 계획/쿼리 수행시간은 미측정.
`checkPlatformAdmin` 호출 감소는 해당 helper 내부 계정 RPC+accounts 조회의 중복을 줄인다.
DB가 보내는 목록의 전체 크기는 그대로다. 서버 검색/페이지네이션은 별도 SQL 설계와 검증이 남아 있다.
추가 캐시나 대규모 리팩터링은 측정 근거가 없으므로 적용하지 않았다.
